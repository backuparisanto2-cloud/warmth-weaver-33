# Import "share-warmth-network" into this project

The GitHub repo is public and is already a Lovable TanStack Start project: an Indonesian kost/property management app with rooms (kamar), floor plans (denah), facilities (fasilitas), income (pendapatan), expenses (pengeluaran), and reports (laporan), backed by a database with photo storage and an AI expense helper.

## What will be done

1. **Copy the app code** — all routes, components, hooks, libs, styles, config, and public assets from the repo into this project, replacing the placeholder home page.
2. **Enable Lovable Cloud** on this project (the app needs database, auth, and file storage). A fresh backend is created — the original project's data does not come along.
3. **Recreate the database** by applying the repo's 3 migrations (tables, grants, row-level security policies, storage buckets) to the new backend.
4. **Restore images** — 5 image assets (floor plans lantai 1-3, rooftop, splash) are stored as references in the repo, not real files. They will be re-generated or, if you have the originals, you can upload them and I'll swap them in.
5. **Wire secrets** — the AI expense feature uses the Lovable AI gateway; it will be reconnected on the new backend.
6. **Verify** — build the app, load each page in the preview, and fix any import or runtime errors.

## Notes / limits

- Existing content of this project's home page is replaced.
- Any data (rooms, tenants, transactions, uploaded photos) living in the original project's database is **not** transferred. If you need it, an export/import step must be added.
- Environment values in the repo's `.env` point at the old backend and will be replaced with this project's own.

## Technical details

- Stack matches this template (TanStack Start v1, React 19, Tailwind v4, shadcn/ui), so dependencies are added via package install: supabase-js, jspdf + autotable, xlsx, pdfjs-dist, recharts, embla, vaul, date-fns, react-hook-form, zod, and the Radix set.
- Files fetched from `raw.githubusercontent.com` at `main`; `src/routeTree.gen.ts` is regenerated by the router plugin rather than copied verbatim.
- Migrations applied in timestamp order; each `CREATE TABLE` verified to carry explicit GRANTs plus RLS policies before running.
- `.asset.json` placeholders under `src/assets/` are replaced with real image files and imported as ES modules.
